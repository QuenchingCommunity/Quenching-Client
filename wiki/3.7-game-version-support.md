# 淬火 3.7 游戏版本支持范围

用户 2026-10-26 更新要求：保留 3.0，并按功能屏蔽。当前客户端内部版本 3.7.0（公开版本 3.7 TEST）支持：

| 界面版本 | 游戏版本 | 着色器 | UI / 皮肤 / DNC |
| --- | --- | --- | --- |
| 2.04 | 2.0.4，含构建号 | shaders203（保留资源目录名） | zip-ui-20、legacy 皮肤表、dnc20 |
| 3.0 | 3.0.0，含构建号 | shaders-300-legacy-hd / de（独立旧 ZIP） | zip-ui-30、现代皮肤表、dnc30 |
| 最新（3.01） | 3.0.1 及以上 | shaders-300-hd / de | zip-ui-30、现代皮肤表、dnc30 |

`src/shared/war3-support.ts` 定义统一判断。检测到 1.x、2.0.0–2.0.3、其他未支持的 2.x 时，在应用版本资源、启用 MOD、安装完整包、执行 MOD 更新、启动游戏及迁移分支资源前拒绝操作。3.0.0 不再整版拒绝。关闭或卸载 MOD 仍可操作。手动选择支持版本不能绕过已检测到的不支持版本；无法读取版本时，可明确选择支持版本，自动模式会提示检查游戏或分支。

主页保留自动检测，以及“2.04”“3.0”“最新（3.01）”。历史 `v203` 偏好迁移为 `v204`；`v1`、`v20` 迁移为自动检测；`v30` 保留独立档位。DE 要求 3.0 或以上。PTR 继续保留独立的确切构建号着色器兼容检查，版本范围本身不授权未知 PTR 的着色器写入。

客户端不提供 `shaders136`、`shaders200`。现代 `shaders.zip` 与独立 `assets/quenching/shaders-300-legacy.zip` 分开；后者恢复 Win/Mac 分发，常规准备检查其存在，默认不重建旧包。`--legacy-source` 仅供显式维护旧资源。2.04 所需的旧式 UI／皮肤／DNC 保留。地形 `t00/t16/t18/t20/t30` 等属于玩家风格选项，不代表游戏版本。

2.04／3.0 均不启用现代辨识度、增强描边或单位缩小；3.01+ 单位缩小仍仅限 HD。完整盘点与其他画质／依赖门槛见 [功能矩阵](war3-version-feature-matrix-20261026.md)。

3.7 首版不向 2.04 提供本轮新增的队伍色 emissive、伪描边／增强描边或单位缩小；已有光照、亮度、地形、树木继续沿用。已核对 shaders203 / dnc20 的跟踪文件与当前 HEAD 无差异；这不是对整个客户端与旧发布版逐字节相同的承诺。独立 HD-only 2.04 实验不合入正式 assets / Latest 或 3.7。

完整包源 `D:/Quenching/QM/Latest` 当前只有活动 `shaders/ps`、`shaders/vs`，无需按旧版目录名称删除其共享资源。历史正式包、签名索引、更新基线不改写；本次源码调整不代表已经正式发布 3.7。

验证：`npm run test:war3-support`、既有 shader-301 / PTR、启动资源、画质切换、UI、安装开关及 MOD 更新回归，然后执行 `npm run build`。发布验收另按 `quenching-release` 清单完成。
