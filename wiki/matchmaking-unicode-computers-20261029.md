# 独立匹配工具 r9.4：中文路径与电脑填充

用户要求支持中文路径，提供电脑填充按钮，难度包含简单、中等、令人发狂。独立工具仍未集成 QM，也不改变客户端/MOD 更新通道。

## 实现

界面与 Node 工作进程间的请求改为 ASCII 安全的 JSON：非 ASCII 字符编码为标准 `\uXXXX`，由 JSON 解码恢复。这样不依赖 Windows 控制台代码页，中文、空格、重音和 emoji 不再因管道编码损坏。读取工作进程输出仍明确使用 UTF-8。

StormLib 插件把文件路径作为窄字符串传给原生库。地图解析已先由 Node 读取用户原始路径，再复制到属于本次解析的 ASCII 原生临时目录；如果用户 TEMP 本身含中文，会选择可写的 ProgramData/Public 等 ASCII 临时根。解析后仅清理自己创建且边界校验通过的 qm-map 随机目录，复制失败也进入 finally 清理。没有修改原始地图。

GUI 增加“电脑填充空位”开关，默认关闭；难度下拉为简单、中等、令人发狂，打开后默认中等。房间列表显示房主的选择，加入者沿用房主设置。每场仍需要两名真人；两人以外的地图可用真人位置才改为电脑，已存在的固定电脑不改难度，地图的阵营、种族、颜色与空白/不可玩位置不被重新编排。自定义地图里电脑如何行动由地图本身的脚本/AI 决定。

难度在 W3GS 九字节栏位中的值分别为 0、1、2。服务端负责最终填充策略，拒绝未知难度，自动匹配按难度隔离；旧客户端不发送该字段时保持 off。创建者已经排队后不能通过重复请求偷偷改变难度。

## 验收

- 42 项 Node 回归测试通过，包含原有队列、地图位置、聊天/操作和新增五项电脑填充测试。
- 三档电脑难度均核对了真正序列化给客户端的 W3GS SLOTINFO 数据，不只是检查 GUI 文字。
- 将完整工具复制到含中文、空格和 emoji 的目录；中文魔兽目录、昵称经过真实 GUI→工作进程→GUI 往返，界面 QA 通过。
- 将 TEMP/TMP 指向中文目录，使用打包后的工作进程选择真实中文/emoji 地图路径、解析并导出中文报告，三档设置往返均通过；过程没有启动 Warcraft III。
- 服务器空闲后部署 `/opt/quenching-match-player-301-lab/releases/20261029-unicode-computers`，更新撮合服务；旧 release 与原 unit 配置保留，可回滚。UDP 辅助服务与 Nginx 未因本次更新重启。
- 在实际公网 WSS 上，用服务器已存的 WarChasers Reforged 12 栏地图和两份协议客户端分别跑简单、中等、令人发狂。三个测试均确认房主策略不能被加入者覆盖，两端收到的所有栏位字节匹配预期；昵称、聊天、操作和正常离开保持可用。
- 公网测试游戏 ID：简单 `77d074eb-6a33-4bfd-a62a-86e330c5da12`；中等 `a50b0b8b-59eb-4f27-a20d-1871b995d788`；令人发狂 `59d398b7-d030-4ca4-96d4-68b13c459c4c`。

以上是 GUI、真实地图解析和协议验收，没有伪称已经用两份真实魔兽验证电脑进图后的行动。本版仍使用 WSS，未混入 QUIC/BBR 传输切换。
