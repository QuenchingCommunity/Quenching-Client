# HD 材质再次调整（2026-10-27）

本轮依据用户最新参数，从当前 HD 标准 BLS 派生，并保留已接入的原生光照和战争迷雾可见性输出协议。

| 参数 | HD 对战 | HD RPG |
|---|---|---|
| 云影 | 移除 | 亮端 1.5，暗端 0.5 |
| 漫反射倍率 | 1.4 | 1.25 |
| 非金属 F0 | 0.04 | 0.05 |
| RGB 饱和度 | 0.95 | 0.95 |
| RGB 线性曝光倍率 | 1.05 | 0.8 |
| 粗糙度输入加法 | 保持基底 | −0.1 |
| 粗糙度输入倍率 | 保持基底 | 0.95 |

HD 对战保留 F90=[1,1,1]、环境镜面倍率 1、F0 倍率 [1,1,1]、阴影环境镜面保留率 1、阴影环境填充倍率 1。RPG 沿用此前 HD、地形、悬崖额外法线倍率 1.5。

粗糙度严格按 ORM 贴图 G 通道映射到实际目标分量，执行 `saturate((G - 0.1) * 0.95)`，随后保留基底已有粗糙度范围映射。金属度、遮蔽、颜色 alpha 均不受这两条新指令影响。漫反射保留原生 Lambert 系数再乘所设倍率；饱和度和曝光只改 RGB。

本轮更新 Retail/PTR 的 RPG、melee 四份 HD 材质，四份配套辨识度 HD 材质及其索引，并重建客户端 `assets/quenching/shaders.zip`。标准、DE、Fog、DNC 和独立 3.0 资源保持本轮开始时的内容。

基底新增的可见性写入器已经存在，因此辨识度重建仅追加队伍色发光，复用当前配套 Fog。逐程序核验写入器尾部指令字节不变，避免套用旧描边写入协议。

验证包括完整相关材质变体的 WARP 创建、22 项实际发光 GPU 检查、14 项实际粗糙度与 RGB 调整 GPU 检查，以及模式／辨识度和光照档位回归。结果与最终部署状态记录于 `artifacts/hd-material-retune-20261027/verification.json`。资产回滚对象保存在 `_tmp/hd-material-retune-20261027/backup/`。

按用户最终选择，当前游戏和客户端继续使用 HD 标准模式、亮度 3；本轮只更新客户端 assets 与资源 ZIP，没有向游戏目录、Latest 或网络源部署。重建后的 ZIP 共 180 项，仅本轮指定的 9 项内容变化；独立 3.0 ZIP 哈希不变。
