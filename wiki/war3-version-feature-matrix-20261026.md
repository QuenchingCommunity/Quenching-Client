# 魔兽版本与功能屏蔽盘点（2026-10-26）

按当前源码和本次本地修正核对，未修改线上清单或真实游戏资源。用户最新决定：保留 3.0 基础支持，按功能和资源兼容性屏蔽，而不是整版排除。

## 版本与基础资源

| 魔兽版本 | 基础支持 | 画面档位 | 专用着色器 | UI／皮肤／DNC |
| --- | --- | --- | --- | --- |
| 2.04 = 2.0.4 | 支持 | SD、HD；DE 不可选，后端降为 HD | shaders203 | UI20、legacy 皮肤、dnc20 |
| 3.0 = 3.0.0 | 本次恢复 | SD、HD、DE | shaders-300-legacy-hd／de，独立旧格式 ZIP | UI30、v30 皮肤、dnc30-hd／de |
| 最新 3.01 = 3.0.1+ | 支持 | SD、HD、DE | shaders-300-hd／de | UI30、v30 皮肤、dnc30-hd／de |
| PTR | 独立兼容门禁 | SD 不受 shader 白名单限制；HD／DE 要求已核验构建 | shaders-ptr-hd／de | 使用现代逻辑档位，不能用手动版本选择绕过着色器门禁 |
| 1.x、2.0.0–2.0.3、其他未支持 2.x | 仍不支持 MOD 资源操作 | 不在本次恢复范围 | 无可分发支持承诺 | 手选 3.0／3.01 不能绕过已检测的不支持版本 |

PTR 当前精确白名单仅为 `3.0.1.24368`；未核验 PTR 的 HD／DE 会在着色器写入和 MOD 启动前被拒绝。版本未知的自动模式会拒绝；无法读取版本时可手工指定受支持资源档位，这不是对未知着色器 ABI 的验证。

不支持版本仍可以关闭／卸载 MOD；客户端的游戏启动入口本身也做版本校验，因此不承诺“MOD 关闭后即可从此客户端启动任意旧版魔兽”。

| 功能 | 2.04 HD | 3.0 HD／DE | 3.01+ HD | 3.01+ DE |

| 高清复古单位／建筑资源包 | 可用，需完整包 | 仅 HD 可用；DE 不可用 | 可用，需完整包 | 不可用 |

3.0 的 DNC 目前与 3.01 共用 3.x 路径及 `isVersion30` 规则，所以普通／对战曲线处理没有独立的 3.0.1-only 门槛；本次只盘点并恢复基础资源入口，没有另行改 DNC 数值。若以后要让某一新光照算法仅限 3.01，应单独拆分该能力，不能靠关闭整个 3.0。

## 与版本无关的屏蔽条件

| 条件 | 屏蔽或限制 |
| --- | --- |
| SD／经典锁定 | 设置页锁定草地、腐蚀之地、物体着色器、后处理阴影／辉光／增强描边、辨识度、水面、地形、树木、光照／亮度、UI 风格、英雄辉光、半身像与模型增强；反和谐入口也禁用。SD 本身和 SD 皮肤档位仍保留 |
| DE 画面 | 水面设置禁用；高清复古包禁用；单位缩小不生效。这不是禁止 DE 的基础物体／后处理功能 |
| 复古地形 | 草地禁用，并将 foliage 设为 false |
| 缺少 VisionMod 路径 | 半身像、模型增强禁用 |
| 未安装完整包 | 水面提前禁用；非原版地形／树木在保存时拒绝；高清复古包与依赖 cos 资源的皮肤不能应用。不能据此屏蔽整个 MOD 开关 |
| 物体着色器或后处理阴影关闭 | 提高辨识度的队伍色扩展不应用，HD 单位缩小恢复；后处理阴影关闭也令增强黑边不生效。辉光开关独立 |
| MOD 关闭 | 保存偏好，不主动重建渲染／光照／地形覆盖；重新开启时按对应版本应用 |
| RPG 旧选项 | 所有版本统一回落普通，不再作为独立当前模式 |
| 资源版本仍为 3.4 | 部分资源设置要求先完成 3.5 桥接；这是 MOD 资源版本条件，不是魔兽 3.0／3.01 条件 |

## 盘点中发现的边界

- 正式服 `supportedWar3Version` 会把所有 3.0.1+（甚至未来 major > 3）归入 v301；这只是当前选择策略，不是对未来构建着色器 ABI 的实测承诺。PTR 有精确构建门禁，正式服目前没有同等细的白名单。
- 手动档位仍会覆盖已检测版本的资源层级。当前硬拒绝解决的是“安装版本完全不受支持”，不是“2.04／3.0／3.01 之间手选不匹配”；比如已检测到 2.04，但手选 v301，后续 DE／新增效果的部分判断仍以选择结果为准。这是需要后续统一按真实检测能力判断的缺口，不能把表中的限制宣称为在任意手动组合下都无法绕过。
- 能力条件分散在设置页、资源包识别和后端效果函数。增强描边的旧版本开关在 UI 禁用，后端选旧 Fog 时也不会装现代增强；但它并不是一个统一的“功能不支持”IPC 错误。盘点按有效结果与实际 UI 分别说明。
- 无完整包时，设置页对水面提前禁用，但非原版地形／树木主要在保存阶段拒绝；这里存在提示时机不一致，不能误归类为游戏版本屏蔽。
- 本轮未修改以上边界的行为，避免把版本支持盘点扩大成新的功能策略。
