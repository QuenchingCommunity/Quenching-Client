# r9.7.1 界面刷新及连接错误修复

用户截图同时显示服务器连接失败及界面通信异常。本次确认其正在运行 r9.7 的 GUI 和配套 runtime。

确定的界面缺陷：逐槽位弹窗替代旧全局难度选项后，旧 ComboBox 已不再填充 Items，但 Receive(state) 仍将 SelectedIndex 设置为 1，从而触发 ArgumentOutOfRangeException。旧 catch 吞下异常，导致每次状态渲染中断且出现笼统通信异常。此前 GUI QA 仍可能从异常前更新的 phase 推进，错误判通过。

修复：移除已废弃控件及赋值；QA 期间任何 Receive 异常立即判失败，实际界面提供异常类型。用真实报告 8867a57e-223d-4875-80da-c4ec81c4479e 的状态做反射回放，旧 r9.7 显示通信异常，新版同样数据正常显示测试编号。

网络记录的独立事实：日志含 UND_ERR_CONNECT_TIMEOUT；检查时 SSH、本机服务及公网 HTTPS 健康接口均成功，DNS A 为 191.40.44.138，服务 instance c0a8e4b5-8767-4e7d-97f7-7ecfa318a2e8。不能据此认定之前超时不存在，也未证明其物理线路根因。

客户端改进：连接容忍时间由 4 秒增至 8 秒，公开健康探测时限由 6 秒增至 10 秒；记录探测及实际请求的具体连接错误码；GET/HEAD 的传输失败最多重试一次，HTTP 错误响应不重试，POST/DELETE 不自动重放。请求取消仍立即生效；域名、TLS SNI 与正常证书验证保持有效。没有更改服务器、防火墙、游戏流量或 QUIC 传输。

验证：88 项回归通过；增加只读重试、错误码保留、失败上限和 HTTP 错误不重试测试，既有写入不重放测试继续通过。GUI 两轮模拟及槽位／昵称检查通过。公网连续 3 次健康查询及所选军团战争地图元数据查询通过。本次没有自动操控、启动或关闭魔兽，也没有重新进行双端实机开局。

交付目录为 Quenching-Matchmaking-Lite-GUI-20261030-r9.7.1-ui-network；r9.7 用户退出工具后覆盖 update.zip，或使用完整包。r9.7 的原产物保留；r9.7.1 不应宣称所有连接故障或对局延迟尖峰已经解决。
