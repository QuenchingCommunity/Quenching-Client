# 不死族单位涂装检查（2026-11-03）

## 结论

当前问题确实存在，主要不是资源缺失，而是皮肤目录把没有新模型的配置也当成了独立皮肤，以及战团之间切换不完整。另有地穴恶魔钻地形态未关联的问题。

本次检查不改动客户端业务代码、玩家配置、Latest 资源或魔兽安装目录。

## 范围与证据

- 检查当前单位页面的全部 15 个不死族单位／形态，不包含英雄与建筑。
- 使用本机魔兽 CASC 的 `Units/UnitSkin.txt`、`Units/AbilityData.slk` 和 `Units/UnitData.slk`，核对原版模型、单位 ID 和召唤／变形目标。
- 核对 `D:/Quenching/QM/Latest` 中的战团模型及贴图；本机对应 `cos` 模型也已部署。
- 本机皮肤配置标记为 `hd`、`v30`、baseline 5。
- 对每个选项用真实的 `writeVersionSkins` 生成配置，并将最终模型与原版比较；模拟两个非原版战团双向切换。
- 11 个真正替换模型的配置全部通过预览解析器解析（几何、材质），其主体模型的非替换纹理引用均能找到资源。此结果不等于游戏内对局／渲染验收，未运行游戏验证。

## 问题一：没有新模型的条目被当作皮肤

位置：`src/Renderer/assets/data/skin-config.ts` 的 `u_u2` 配置，以及 `skin-panel-catalog.ts` 的 `builtInSkins`。

- `u_u2:ugho` 的 `file` 是原版 `units/undead/Ghoul/Ghoul`。该选项的僵尸图标容易让玩家误以为会更换外形。
- `u_u2:uske`、`u_u2:uskm` 只有 `unitSound=Skeleton`，连声音也与游戏基线相同。单体目录只判断“存在配置行”，因此错误地把它们列为皮肤。
- 这些定义在历史版本配置中已经存在；本次核对过 Git 的 3.3 配置。新单体菜单直接复用战团行，使这些非外观替换条目也成为了独立选项。
- `writeVersionSkins` 会用原版字段补全没有指定的模型，所以这两个骷髅选项最终确实写回原版模型，切换操作成功也不会改变外形。

正确修复方向：单体列表只暴露有实际外观效果的选择；同模型／声音恢复行仍可作为战团恢复规则使用。食尸鬼的图标应与实际模型一致。不要为凑齐战团而随意给它们指定另一款模型。历史保存的这三个 ID 需要兼容处理，不能直接变成找不到皮肤的错误。

## 问题二：战团切换会混入上一套的模型

位置：`skin-panel-catalog.ts` 的 `warbandChoices`。它只提交当前战团包含的单位，没有处理上一套额外改过的单位。

使用真实皮肤写入函数复现：

- `u_u2 → u_u3`：`uban`、`ucry`、`ufro` 继续使用诅咒教派的模型。
- `u_u3 → u_u2`：`umtw` 继续使用僵尸战团的模型。
- 因此“战团已应用”不代表当前外观完全对应这一套预设；重新打开时也可能无法将当前混合配置识别为完整战团。

正确修复方向：为战团明确声明完整目标状态，对战团共同管理范围内、当前方案未替换的单位恢复原版；保留战团范围之外的玩家自选。单体选择则仍只修改该单位。

## 问题三：地穴恶魔的钻地形态未覆盖

游戏 `AbilityData.slk` 中，`Abur.UnitID1=ucrm`；单位基线中 `ucry` 和 `ucrm` 是两个独立的 `skinnableID`。

当前诅咒教派只替换 `ucry`，钻地后的 `ucrm` 没有对应覆盖。该形态无法自动继承普通形态的皮肤。修复时还应确认替换模型具备钻地／交替动画，不能只机械复制一个模型路径。

石像鬼的 `Astn.UnitID1=ugrm` 也已核对。目前石像鬼没有内置战团替换模型，所以本次没有对应的现有失效选项；今后给石像鬼添加皮肤时需要处理石像形态。

## 已排除：骷髅召唤 ID 配错

游戏原始技能表中的实际引用为：

- `Arai`：普通骷髅 `DataC1=uske`，升级后 `DataC2=uske`、`DataD2=uskm`。
- `AIrd`：`DataC1=uske`。
- `ACrd`：`DataC1=uske`。

因此骷髅战士、骷髅法师的目标 ID 没有配错。僵尸战团确实向这两个正确的 ID 写入了不同模型，其模型与主体贴图在本机均可读取。如果玩家使用僵尸战团仍然完全不变，需要进一步核对其实际运行的客户端构建、当前画质和部署到对应游戏分支的配置，不能由“资源存在”推出游戏里一定生效。

## 上次检查的不足

上次“45 个配置、无资源缺失”只验证了路径、资源引用和配置写入，未验证每个选项与原版的外观差异、完整预设切换和变形单位。该结果不足以证明所有皮肤都能产生预期变化；本次已补上这些检查。
