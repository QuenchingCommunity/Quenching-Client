# 3.7 客户端发布前刷新（2026-11-08）

用户已验收本地 3.7 候选，并要求准备发布和推送 GitHub；随后将光照按钮文案“对战级光照”简化为“对战”。正式内部版本保持 3.7.0，对外显示 3.7。准备期间不替换官网活动索引、version.que 或主站部署，不提升 GitHub Latest。

本轮主要刷新客户端。Latest 资源仓库仍以 de34150146eeaf59e930561b65ec2861af98f0cd 为已准备的 3.7 / sequence 39 输入；没有新增 MOD 资源补丁或重做完整包 A/B。客户端的附加资源与 Latest 分属不同发布职责。

客户端包含以下改动：

- 总体亮度默认值为 RPG 0.85、标准 1.1、对战 1.4。已有有效自定义值在重启时保留，选择模式或预设时应用新默认。
- 对战预设使用 230°、阴影 20%，关闭大气光和旋转光照。阴影滑杆的普通默认值为原 DNC 的 50%，可独立恢复方向及阴影默认。
- 方向、阴影和旋转只修改 unit DNC，terrain 与 portrait Rotation 保留原始参数；启动同步可修复旧错误的 terrain 方向。
- 光照页面不再使用阻挡控件的浮动提示，HDR 与总体亮度同行，设置保存尊重显式关闭值。
- 对战草地沿用已验收的 BC3 资源，RGB 提亮 12%，透明通道保留；旋转光照使用 97 帧 Campaign 单位轨迹，开启时锁定 45°／阴影 40%，关闭后恢复保存值。
- 关闭淬火时先还原该分支的第三方资源，再执行受管文件停用；启动检查显示实际错误步骤与位置，保留玩家独立目录及另一分支。
- Windows 与 Mac 外层便携分发改 ZIP；内部五个 resources-*.7z 不变。Mac 工作流显式选择正式构建，原生 ditto 解压交付 ZIP 后验证签名、权限、链接、原生模块及真实 renderer/preload/IPC 启动。

Windows 正式构建可不做 Authenticode，自动更新 Ed25519 验签、SHA-256 与大小校验仍保留。正式产物编译移除 TEST 初始化、通道选择、预览及离线测试 UI／IPC。Mac 继续手动更换便携包，不使用 Windows 自动更新清单。

发布记录区分源码推送、候选上传、下载验收、旧版自动更新验收及正式入口切换。前次 GitHub 3.7 候选的字节和验证结论不能代替本轮；新的 Windows 更新目标需从真实 3.6.1 官方基线生成、签名和验证。所有准备脚本及中间产物放在 `_tmp/release-ready-20261108/`，小型私有记录保存在 `_irys/releases/release-3.7-20261107/client-refresh-20261108/`，交付资料位于 `__Bin/release-3.7-20261107/`。
